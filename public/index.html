Update Kilo

Reinstalls the global kilo CLI. On Windows the binary is locked while any Kilo session is running, so the update force-stops every Kilo instance on this machine first — including other terminals and any open chat. The dashboard server keeps running; reopen Kilo and restart your panes afterward.

Keyboard shortcuts

s — toggle bulk-select mode

Ctrl/Cmd + A — select all panes (in select mode)

Esc — exit select mode / close overlays

Ctrl/Cmd + Enter — start the focused pane

Ctrl/Cmd + Shift + C — copy selection

Ctrl/Cmd + V — paste
